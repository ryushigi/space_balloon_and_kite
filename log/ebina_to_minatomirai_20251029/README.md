# ebina_to_minatomirai_20251029について

海老名からみなとみらい駅までのGPSデータおよびICM-20948データとなっている。

`space_balloon.py`をGPSデータで高度を使用する上でBME280から算出した高度を使用するようにしている。
この計測ではBME280は使用していないため、movie.csvにダミーでデータを入れて算出しているためBME280は実際の計測データではない。
なお、この計測は30FPSで動画撮影した場合をダミーモードで動作させているため、動画データは存在しない。

## 使用用途

GPSおよびICM-20948データを用いて、フィルターをかけてデータ加工を行うことでノイズ除去を試行するために使用する。
